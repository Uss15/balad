# Balad Heritage Hub

أنت مطور ويب محترف متخصص في المواقع العربية RTL.

اسوي لي ملف HTML واحد كامل يحتوي على:

الموقع الرئيسي:

تصميم احترافي باللغة العربية RTL

ألوان أخضر وأبيض مع لمسات ذهبية

قسم رئيسي (هيرو) مع شعار واسم المعمل

قسم "من نحن" مع تاريخ معمل تعليب بلد للمنتجات الغذائية في قضاء بلد، صلاح الدين، العراق

قسم "منتجاتنا" مع بطاقات المنتجات (معجون طماطة وغيرها)

قسم "لماذا نحن" مع مميزات المعمل

قسم "تواصل معنا" مع عنوان ورقم هاتف

متجاوب مع الجوال بالكامل

لوحة الأدمن:

مخفية تماماً عن الزوار

تنفتح فقط بالضغط على منطقة مخفية في الفوتر 5 مرات متتالية

محمية بكلمة سر بعد الضغط (اجعلها: balad2025)

بعد تسجيل الدخول تظهر لوحة تحكم كاملة تتيح:

تعديل جميع النصوص والعناوين في الموقع

تغيير الألوان الرئيسية

تغيير نوع الخط وحجمه

رفع صور وعرضها في أقسام المنتجات

إضافة روابط فيديو يوتيوب وعرضها

حفظ كل التعديلات في localStorage تبقى بعد إغلاق المتصفح وتنعكس فوراً على الموقع

تقنياً:

كل شيء في ملف HTML واحد فقط

CSS وJavaScript مدمجان في نفس الملف

بدون أي مكتبات خارجية

لا يوجد أي رابط أو زر واضح يدل على لوحة الأدمن

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```
